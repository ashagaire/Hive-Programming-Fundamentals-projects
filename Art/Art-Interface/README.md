# Art Interface
A web interface for text-based art where you give the text data and it will convert it to a text-based art.

<br/>
<hr style="border: 2px solid blue;">


## Project Overview 

A web interface for text-based art, where you give text as an input and this application converts it into a piece of text-based art.


## Setup and Installation
Installation 
1.Clone the repository:
```bash  
git clone https://github.com/ashagaire/Hive-Programming-Fundamentals-projects.git
cd Hive-Programming-Fundamentals-projects/Art/Art-Interface
```
2.Initialize the Go module:
```bash  
go mod init interface
```

3.Verify Go is installed:
```bash
go version
```
